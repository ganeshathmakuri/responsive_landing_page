## Project Overview

The Responsive Landing Page is a modern React-based landing page designed for a houseplant shop. It focuses on delivering a clean, visually appealing browsing experience with a responsive layout that works smoothly across desktops, tablets, and mobile devices.

The project highlights the use of Bootstrap, custom styling, and interactive components such as a collapsible mobile navigation menu to create an engaging and professional storefront landing page.

## Project Objectives

- Build a responsive and mobile-friendly landing page.
- Design a modern layout for an e-commerce style brand.
- Create a structured hero section with strong call-to-action buttons.
- Implement an accessible mobile navigation menu.
- Present product benefits and brand messaging clearly.
- Deliver a polished UI using React and Bootstrap.

## Features

- Responsive Bootstrap layout for all screen sizes.
- Mobile navigation toggle for compact screens.
- Hero section with promotional content and CTA buttons.
- Benefits or value proposition section.
- Clean product/brand-focused design.
- Reduced motion and accessibility-conscious UI behavior.

## Technologies Used

- **React.js** – Building the user interface and app structure.
- **JavaScript** – Implementing component logic and interactivity.
- **HTML5** – Structuring the page content.
- **CSS3** – Styling and layout customization.
- **Bootstrap 5** – Responsive UI components and layout system.
- **Git and GitHub** – Version control and project hosting.

## ⚙️ Installation and Setup

### Prerequisites

- Node.js and npm
- Visual Studio Code
- Git

### Step 1: Clone the Repository

```bash
git clone https://github.com/ganeshathmakuri/responsive_landing_page.git
```

### Step 2: Navigate to the Project Folder

```bash
cd responsive_landing_page
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Run the Application

```bash
npm start
```

This will start the React development server and open the landing page in the browser.
